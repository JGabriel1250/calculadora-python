# Calculadora Python

Calculadora simples desenvolvida em Python para praticar conceitos básicos como:

- Funções
- Módulos
- Tratamento de erros (`try`, `except`)
- Entrada e saída de dados

## Estrutura

- `calc_exercicio3.py`: script principal
- `matematico.py`: módulo com operações matemáticas

## Como executar

```bash
python calc_exercicio3.py
